# Swing-Intraday-Mean-Reversion-Using-VWAP-
Long när pris är över t.ex. 2.0 standardavikelser från vwap. Exit på vwap
Short när pris är under t.ex. 2.0 standardavvikelser från vwap. Exit på vwap
Vi börjar testa in sample på EURUSD 1 hour. Vi hypotiserar om att sessionsfönster under asia session är fördelsaktigt här eftersom det är mindre volatilt och därmed mer attraktivt för mean reversion under dessa timmar. Vi kommer även undersöka när vi bör återställa
vwap verktyget, eftersom det är sessions ankrat
